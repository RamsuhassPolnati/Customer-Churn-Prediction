# Customer Churn Prediction

## Project Overview

This project uses machine learning to predict customer churn in a telecommunications company.

The goal is to identify customers who are likely to leave and support targeted customer retention strategies.

## Business Objective

Identify customers who are likely to churn and support targeted customer retention strategies.

The project evaluates machine learning models using accuracy, precision, recall, and F1-score.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Jupyter Notebook

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Encoding
5. Train-Test Split
6. Feature Scaling
7. Model Training
8. Hyperparameter Tuning using GridSearchCV
9. Model Evaluation
10. Final Model Selection

## Final Model

Logistic Regression was selected as the primary model based on the evaluation results and its balance of performance metrics.

The other models were evaluated for comparison.

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Conclusion

This project demonstrates the complete machine learning workflow for customer churn prediction, from data preprocessing to model evaluation and selection.

The results provide insights into the trade-offs between identifying churn customers and minimizing false positives.
